Fatigue and alertness check

Enter when you woke up, the time now, and how long you slept. The tool estimates how alert you are, using a simplified version of the two-process model of sleep regulation.

For learning only. This is a simplified model and must not be used for real flight-safety decisions. It assumes you woke up within the last 24 hours and ignores caffeine, illness, stress, and time zone changes.
